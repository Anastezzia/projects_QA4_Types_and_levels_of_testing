### Модули и субмодули 

### **1. Общее состояние приложения** 

- Приложение корректно открывается (без ошибок)

- Приложение корректно возобновляется после сворачивания

- Если приложение поддерживает сохранение сессии — при повторном открытии отображается незаконченный маршрут

### **2. Основные элементы приложения**

- Корректно отображается название приложения "Найди и иди" 

- Корректно отображаются поле для ввода названия магазина с плейсхолдером "Введите название магазина" и поле для выбора типа магазина с плейсхолдером "Выберите тип магазина"

- Кнопка “Поиск” отображается и выделяется синим цветом 

- Кнопка «Построить маршрут» содержит иконку в виде изогнутой стрелки, цвет кнопки белый

### **3. Функциональность приложения** 

- Все кнопки на сайте реагируют на нажатие

- Поле "Введите название магазина" доступно для ввода и принимает заявленное количество символов

- В поле "Введите название магазина" сохраняются результаты предыдущих поисков 

- Поле "Выберите тип магазина" кликабельно и представляет собой выпадающее меню со следующими вариантами выбора значений:

  1. «Продуктовые магазины»

  2. «Магазины стройматериалов»

  3. «Аптеки»

- Карта реагирует на скролл и зум

- Успешные результаты поиска отображаются в виде флажков на карте

- Кнопка «Поиск» активна при заполнении минимум одного поля и неактивна, пока не заполнено хотя бы одно из полей ("Введите название магазина" и/или "Выберите тип магазина")

- Кнопка «Построить маршрут» кликабельна в следующих случаях:

  1. Найден результат поиска введенного пользователем названия магазина и выбран его флаг на карте

  2. Выбран тип магазина (маршрут будет построен до ближайшего магазина с указанным типом)

- При нажатии на кнопку «Построить маршрут» название кнопки меняется на «Отменить маршрут» 

- Кнопка «Отменить маршрут» кликабельна и выполняет свою функцию

### **4. Юзабилити** 

- Текст читаемый, отсутствуют ошибки

- Карта отображается корректно и в хорошем качестве 

- Простота навигации в приложении 

### **5. Адаптивность**

- нет “поломанной” вёрстки (съехавшие блоки, наложения текста)

- приложение корректно отображается на мобильных устройствах

- нет горизонтального скролла (только вертикальное прокручивание страницы)
